# Beach Lab (web app / PWA)

Si pubblica gratis su GitHub Pages e si aggiunge alla Home dell'iPhone: si apre a schermo intero, senza barre di Safari, funziona offline e non scade mai.

## Pubblicazione
1. Crea un account su github.com e un repository **pubblico** chiamato `beachlab`.
2. Carica tutti i file di questa cartella nella radice del repository (GitHub Desktop → *Add local repository* → *Publish*, oppure *Add file → Upload files* dal sito).
3. Su GitHub: **Settings → Pages → Source: Deploy from a branch → main / (root) → Save**.
4. Dopo circa un minuto l'app è su `https://TUONOME.github.io/beachlab/`.

## Installazione su iPhone
1. Apri l'indirizzo in **Safari**.
2. Tocca **Condividi → Aggiungi alla schermata Home**.
3. Apri **Beach Lab** dall'icona: da quel momento va a schermo intero.

I dati (pesi e storico) sono salvati sul telefono. Aprila sempre dall'icona in Home, non da Safari, perché i due contenitori di dati sono separati.

## Aggiornamenti
Se modifichi i file e li ricarichi su GitHub, l'app si aggiorna da sola alla riapertura successiva.
